- The popup has a new look with a "Check this site" switch and a "Pause in this tab" button: a pause stops checking only in the current tab and ends when you reload the tab, open another page in it or close it.
- The popup says "Inkling cannot check this page" on browser pages and extension stores instead of showing an empty site name, with the switch and the pause button disabled.
- Turning a site off in the popup now also works on sites whose address starts with "www." (such as www.reddit.com), and the marks disappear within a second instead of after up to a minute. Turning a site off in the popup also ends a pause set for that tab, and switching "Enable on new sites" in the settings now updates open pages at once.
- The settings page has a new, cleaner look. The "Delay" field now refuses an empty, negative or too large value (above 60000 ms) with a message instead of silently saving 0 for an empty one, and pressing Escape while setting the apply-suggestion hotkey keeps the old one.
- The settings page now shows "Could not load the settings: ..." when loading fails, instead of showing defaults that a later edit could save over your real settings. A request that fails inside the extension now shows an error instead of waiting forever.
- The hotkey button on the settings page now tells screen readers when it is waiting for keys. The popup switch springs back to its old position when saving the change fails.
- The settings page and the popup no longer load fonts from Google.
- The Inkling icon is now a blue and yellow chisel-tip highlighter in place of the reading glasses, in the toolbar, the extensions list, the popup and the settings page. The toolbar gets real 16 and 32 pixel versions, so the icon stays sharp and readable on dark toolbars.
- Clicking into a marked word now puts the cursor there, so you can fix it by typing. The suggestion card still opens next to the word but no longer takes the keyboard; typing, Esc or a click elsewhere closes it, and pressing the activation key twice still moves the keyboard into it.
- Mistakes are marked with a soft highlighter fill instead of a thick underline, in three colors: red for spelling, amber for grammar and punctuation (including all comma rules and mixed-up words such as "their/there" or "das/dass"), blue for style.
- The settings page and the popup window are titled "Inkling" instead of "Harper".
- The suggestion card is now one small card instead of two panels: category, explanation, suggestions, and icons for "Add to dictionary", "Disable rule" and "Settings". The × in its corner ignores the mistake, replacing the "Dismiss" button, and the random "Tip" box is gone.
- New: suggestions in web pages now come from a LanguageTool server set under `Server URL` in the settings, so German and the other LanguageTool languages are checked. Harper's built-in English checker is gone.
- New settings `Preferred Variants` (for example `de-CH`), `Disabled Rules` and a `Clear` button for ignored suggestions. "Disable rule" in a suggestion now disables the LanguageTool rule.
- The extension no longer contacts writewithharper.com: the version check, the site and lint feedback forms, the review banner and the install and uninstall pages are removed.
- Checking waits 500 ms after typing stops by default (was 0), so the server gets one request per pause instead of one per keystroke.
- The popup now strips a leading `www.` from the site name it shows.
